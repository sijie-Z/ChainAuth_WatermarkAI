> 面向现场演示与评审走查。默认演示库使用 `.scratch/demo/ui.db`，前端 `http://localhost:5173`，后端 `http://localhost:5000`。

## 2. 十分钟主流程

### 2.1 首页（1 分钟）

- 指出首页的“四道工序”：上传 → 水印 → 存证 → 授权。
- 底部台账显示 16 / 16 / 16 / 2，与资产库一致。
- 强调：照片是真实园林实景，不是占位图；演示库默认已给全部已发布资产嵌入水印并模拟存证。

### 2.2 资产档案与检索（1 分钟）

- `/assets`：按园林、类型、标签、上传日期、上传者筛选；搜索“拙政园”“D16”验证关键词覆盖标题/编码/园林/上传者。
- 卡片缩略图来自真实照片，列表支持网格/列表切换。
- 进入“拙政园 · 卅六鸳鸯馆水岸”（`ZZY-IMG-20261021-D16`）。

### 2.3 资产详情与证据链（2 分钟）

- 右侧显示水印 ID、交易哈希、证书编号；说明默认是本地模拟链，证书页会标注。
- 点击“溯源查询”或“证书”可核对。
- 下方标签页：
  - 证据链：上传 → 水印 → 存证 → 证书 → 发布 → 授权 → 下载的时间线；
  - 讨论：发表评论、回复；
  - 标注：在图上框选区域、标记“问题/建议/已解决”；
  - 版本：上传新版本会退回草稿并重置当前水印/存证，历史证书保留。
- 若演示 PDF/三维资产：详情页可直接预览 PDF；GLB/GLTF/STL/OBJ 可拖拽旋转缩放（需所有者/管理员或有效授权）。

### 2.4 溯源（1 分钟）

- `/trace` 选择“水印 ID 溯源”，输入资产详情页显示的水印 ID（示例 `ZZY-IMG-20261023163244-E77D`，以当前库为准）。
- 应命中资产并展示证书、链上记录与核验结果。
- 也可在“上传图片溯源”上传从平台下载的水印图片；大面积裁剪后无法还原是算法边界，需结合存证核验。
- “提交侵权线索”可上传疑似副本/填写链接，管理员在后台研判。

### 2.5 授权、下载与指纹（2 分钟）

- 用 `user1` 打开资产 → 申请授权：填写使用目的、渠道、格式、地域、下载次数。
- 用 `adm1` 登录后台“授权审批 → 待审批”一级通过；再用 `adm2` 二级通过。
- 回到 `user1` 的“我的授权 → 授权记录”：
  - 查看合同，点击“打印 / 另存 PDF”，展示抬头、编号、范围与签署栏；
  - 下载时申报用途与地域；成功下载的影像会带可见页脚（资产编码、授权编号、账号、指纹码），盲水印仍保留；
  - 故意选择未授权地域/格式，返回 403 并写入“超范围拒绝”。
- 打开 `/downloads` 查看下载记录与指纹码；管理员在 `/admin/downloads` 查看全平台台账。

### 2.6 后台与运维（2 分钟）

- `/admin` 仪表盘：真实统计、资产类型环图（中心显示总数）、水印趋势、最近业务活动、待办。
- `/admin/license/usage` 使用报表：有效/到期/撤销、配额、拒绝原因、下载趋势、版本待重审，支持 CSV 导出。
- `/admin/tasks` 任务队列：在线 worker 心跳、最老排队任务、积压/超时告警；失败任务可重试。
- `/admin/infringements` 侵权线索：举报文件、水印匹配、受理/确认/驳回；支持一次最多 20 个文件批量巡检。
- `/admin/notifications` 通知渠道：SSE 已启用、SMTP 未配置时明确提示；Webhook 可配置通用 JSON/企业微信群机器人并发送测试。
- `/admin/assets` 资产管理：批量通过/驳回待审资产、当前页 CSV 导出。

### 2.7 命令行收尾（1 分钟）

```bash
cd backend
python -m flask tasks status
python -m flask storage report --min-age-hours 24 --limit 10
python -m flask backup create
python -m flask backup list
```

- `tasks status`：在线 worker、积压与健康度；`--check` 可用于容器健康检查。
- `storage report`：只读盘点，列出数据库未引用的文件，不会自动删除。
- `backup create/list`：SQLite 使用在线备份 API 并做完整性校验；恢复前自动保留回滚副本。

## 3. 必须如实说明的边界

1. **区块链默认是本地模拟**：`BLOCKCHAIN_ENABLED=false`，交易哈希/区块号为本地生成，不能用于链上复核。接入 FISCO BCOS 需配置节点、私钥与合约。
2. **AI 默认关闭**：未安装模型/未配置 `ZHIPU_API_KEY` 时接口返回 503，不会伪造结论。
3. **邮件/Webhook 需要外部配置**：SMTP 未配置时不会假装发送；Webhook 仅支持通用 JSON 与企业微信群机器人，不含企业微信应用消息。
4. **水印边界**：可抵抗 JPEG q50、噪声、50%–150% 缩放；大幅裁剪会破坏嵌入区域，需要结合存证与人工核验。
5. **三维预览**：优先支持自包含 GLB；GLTF 需内嵌缓冲/纹理；FBX 与 Office 文档仍为下载查看。
6. **存储抽象**：当前默认本地磁盘，MinIO 为可选组件尚未接入；孤儿文件只报告不自动清理。
7. **演示账号**：生产初始化默认不创建 `123456` 演示账号，管理员密码未配置时随机生成；演示部署可显式开启。

## 4. 常见现场故障与处理

| 现象 | 处理 |
|------|------|
| 首页统计为 0 或详情显示“未嵌入/未存证” | 演示库被重置后未跑水印/存证：`python scripts/seed_demo_assets.py --reset`（会重建演示库） |
| 任务一直排队 | 检查 `flask tasks status`；启动 `docker compose` 的 worker 或 `flask tasks run` |
| 预览提示“获得授权后可在线预览” | 属正常权限控制；用所有者/管理员账号或先完成授权 |
| 合同打印窗口被拦截 | 允许浏览器弹窗后重试；或在打印视图中使用“另存为 PDF” |
| 溯源上传命中失败 | 确认上传的是平台生成的水印副本；裁剪过的图片可能超出算法边界 |
| 端口冲突 | 后端 5000、前端 5173；关闭旧进程后重启 |
