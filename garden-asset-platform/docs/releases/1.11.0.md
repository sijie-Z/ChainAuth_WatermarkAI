# v1.11.0 · 跨页面断点续传与一致性加固

这一版把“大文件上传中断后怎么办”补成了完整闭环，并集中修复了一批并发、安全与可用性问题。

## 本版新增

- **跨页面断点续传**：未完成的大文件会话在服务端保留 48 小时。刷新页面、关闭浏览器甚至换一台设备后，上传页会列出“未完成的上传”，重新选择同名同大小文件即可从断点继续；不需要的会话可直接放弃并清理已上传分块。
- **续传前同步元数据**：恢复会话时，用户修改过的标题、所属园林、描述与标签会先同步到会话，再继续上传，避免旧会话覆盖新填写的信息。
- **会话运维**：`GET /api/assets/upload/sessions`、`DELETE /api/assets/upload/session/:id`、`PATCH` 元数据同步；`flask uploads list` / `flask uploads cleanup --yes` 可巡检与清理过期会话，调度器每日自动回收。
- **历史版本流式下载**：版本下载改为短时票据 + 浏览器直接落盘，不再把大版本整包读进 JS 内存。
- **版本感知的授权提示**：资产新版本发布后，旧授权会明确标记“需重新申请”，下载按钮禁用并给出重新申请入口。
- **缩略图按版本刷新**：列表、收藏、合集与相关资产使用当前版本号作为缓存键，新版本上传后不再显示 24 小时旧图。

## 本版修复

- 下载票据签发不提交指纹记录，导致指纹码与文件/台账不一致并持续产生副本文件。
- 授权与分享下载次数的并发竞态：改为原子条件更新，超限请求无法同时通过。
- 断点续传重复文件探测泄露他人资产 ID/编码/状态；分块写入改为锁内定位重写。
- PDF 预览被全局 `X-Frame-Options: DENY` 拦截，现仅预览响应放行同源 iframe。
- 审批与删除并发时，已删除资产可能被改回 `published`；版本号并发冲突返回 500；任务对账可能复活已完成任务。
- 授权期限非法值被静默当成永久授权；地域申请未校验枚举。
- 文件魔数校验补齐 MP4/MOV/AVI/MKV、Office、CAD、GLTF/FBX 与文本格式，拒绝 0 字节文件。
- 退出登录误报“登录已过期”；编辑著录信息可能清空标签；批量上传第 11 个文件起触发限流。
- 我的资产/我的授权快速切换筛选时旧响应覆盖新结果；一级审批弹窗展示会被丢弃的有效期字段。
- 矢量资产不再显示必然 404 的主图预览，改为提示下载后用 GIS 软件查看；标注页签保留，可查看/处理已有标注。
