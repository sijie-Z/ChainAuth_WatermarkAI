# v1.12.0 · 全文件续传、并发防护与可选 MinIO

本版把上传恢复、并发写入和对象存储三条链路补齐，默认本地磁盘行为不变。

## 本版新增

- **全文件断点续传**：所有文件点击“开始上传”后都进入会话，小文件也可跨刷新恢复。浏览器按 1MB 分块计算完整 SHA-256，服务端完成前复核；同名同大小但内容不同的文件不能误认领。
- **写入租约**：`POST /api/assets/upload/session/:id/claim` 签发 120 秒租约。PUT/PATCH/complete 校验租约；同一标签页用 sessionStorage 保存租约，刷新可立即继续，其他标签页不能并发写入。
- **失败可恢复**：会话创建失败清理临时目录；合并阶段数据库失败把文件移回原会话，避免重新上传。
- **可选 MinIO**：`STORAGE_BACKEND=minio` 时新原件与历史版本写入 `minio://bucket/key`，自动建桶；旧本地绝对路径与新对象引用可混存，默认 `STORAGE_BACKEND=local`。
- **对象存储链路**：普通/续传上传、版本上传/恢复、下载/预览/分享、证据包、链上哈希、水印/AI/指纹处理均支持对象引用；对象下载流式返回，预览支持单段 Range，应用内继续执行授权与配额校验。
- **部署状态**：compose 提供 MinIO 配置与健康检查，后台系统状态返回存储后端和桶名（不返回密钥）。

## 本版修复

- 模型/文档/视频无盲水印时异步存证被 worker 错误拒绝。
- 换版后历史授权可能继续下载旧文件指纹：指纹记录绑定源文件 SHA-256，新版本生成新副本，旧台账保留。
- 任务取消与领取竞争、SQLite 锁等待导致的 500。
- 下载/分享在文件发送失败时已扣配额的问题；指纹生成异常只回滚保存点。
- 详情页切换资产仍显示旧数据、授权在中国时区提前失效、命令面板旧搜索覆盖新关键词、刷新 Token 永久挂起、adm1/adm2 无法批量审批。
- 上传过程中修改表单影响已处理文件；历史相对路径预览失败、续传完成徽标残留。

## 当前边界

- 旧文件不自动搬迁；缩略图、水印、指纹和证据包临时文件仍依赖本地共享卷。
- 对象存储下载/预览由应用代理，未提供预签名直传；多段 Range 未开放。
- 存储容量/HA/旧文件迁移、S3 厂商兼容性和真实容器性能仍需专项验收。
