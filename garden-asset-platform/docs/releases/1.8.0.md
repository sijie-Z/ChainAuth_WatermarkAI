# v1.8.0 · 苏州园林数字资产平台完整交付

发布日期：2026-10-24

## 本版亮点

- **端到端闭环**：上传 → 水印 → 版本级存证 → 双重审批授权 → 下载指纹 → 公开溯源 → 证据包导出/核验 → 审计日志 HMAC。
- **大文件体验**：资产下载、在线预览与公开分享下载全部改为短时票据直链，浏览器流式读取/落盘，不再把大文件读入 JS 内存；超过 25MB 的预览需手动加载。
- **资产生命周期**：回收站与恢复、标签整体编辑、版本上传/恢复、评论与区域标注、合集/收藏、公开分享。
- **稳定性**：缺失文件统一返回 404 而非 500；E2E 覆盖真实票据下载、分享下载、回收站、审计与三套后台报表。
- **交付材料**：14 张真实界面截图、1 分钟带字幕演示视频（MP4/GIF/封面）与可复现的 `frontend/scripts/capture-media.mjs`。
