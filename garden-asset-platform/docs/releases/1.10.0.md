# v1.10.0 · 大文件分块断点续传

发布日期：2026-10-25

## 本版新增

- **断点续传上传**：8MB 以上文件自动切换为 4MB 分块上传；中断后向服务端查询已接收偏移并从断点继续。
- **完成后统一校验**：重新校验魔术字节、SHA-256 与重复文件，再创建资产、v1 版本、缩略图，并进入原有水印/存证链路。
- **会话持久化**：`upload_sessions` 表记录用户、元数据、期望大小、已接收偏移和临时路径；临时目录 `uploads/resumable/<uuid>`。
- **偏移保护**：分块必须严格按 `X-Upload-Offset` 追加，错位返回 409 与当前偏移；跨用户访问返回 404。
