# v1.9.0 · 账号找回、邮箱验证与上传并发

发布日期：2026-10-25

## 本版新增

- **自助找回密码**：登录页“忘记密码”→ 邮件一次性链接（30 分钟、单次、密码变更后失效）→ 重置后撤销旧 Token；开发环境未配置 SMTP 时返回调试链接，生产环境不返回。
- **邮箱验证**：账号设置发送 24 小时验证链接，验证状态写入用户信息；变更邮箱后自动重置验证状态。
- **上传并发**：批量上传并发度 2，多文件上传与后续水印/存证队列并行推进，缩短等待时间并限制 CPU 峰值。

## 安全与稳定性

- 邮箱验证/重置链接使用独立 salt 的签名 token，绑定当前密码或邮箱指纹；链接不可跨账号、跨邮箱复用。
- 重置密码后调用统一 Token 失效机制，旧 access/refresh token 立即失效。
- 生产环境默认不回显调试链接；`AUTH_LINK_RETURN_TOKEN=false`。
