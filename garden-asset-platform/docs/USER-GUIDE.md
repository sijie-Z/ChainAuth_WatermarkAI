# 使用指南

> 苏州园林数字资产安全分发与溯源系统 · 3 分钟上手

这份文档对应站内 [`/guide`](http://localhost:5173/guide) 页面，按真实业务流程组织。第一次使用建议先读“快速走一遍”，再按角色查看对应章节。

## 1. 平台解决什么问题

园林影像、图纸和三维模型在传播中很容易脱离出处。平台把四件事串成一条证据链：

1. **数字水印**：把资产唯一标识写入影像频域或矢量坐标，常见压缩、缩放、噪声后通常仍可提取；具体到某张图片的恢复情况可用“水印实验室”实测。
2. **存证记录**：文件哈希、水印标识和权利人信息生成存证记录与证书。默认使用本地模拟链，配置 FISCO BCOS 节点后才写入真实联盟链；证书页会明确标注当前模式。
3. **双重审批授权**：使用申请经一级、二级审批后生成授权记录，下载行为持续回流台账。
4. **全链路溯源**：上传一张图片即可提取水印、定位资产并关联存证与授权记录。

## 2. 快速走一遍（推荐顺序）

| 步骤 | 操作入口 | 使用角色 | 预期结果 |
|------|----------|----------|----------|
| 1 | `/login` | user1 | 进入资产档案，看到“我的授权” |
| 2 | 资产档案 → 上传资产 | 普通用户 / 资产管理员 | 生成草稿，列表出现缩略图 |
| 3 | 资产详情 → 嵌入水印 | 上传者 / 资产管理员 | 任务进入后台队列，状态变为“已嵌入”并得到水印 ID |
| 4 | 资产详情 → 上链存证 | 上传者 / 资产管理员 | 生成交易哈希与当前版本存证证书 |
| 5 | 资产详情 → 提交发布 → 后台审核 | 上传者 → asset_mgr | 资产进入公开列表 |
| 6 | 资产详情 → 申请授权 | 普通用户 | “我的授权 → 审批中”出现申请 |
| 7 | 后台 → 待审批 | adm1，然后 adm2 | 两级通过后生成生效授权 |
| 8 | 资产详情 → 下载 / 溯源查询 | 被授权用户 / 任何人 | 下载成功；上传图片可溯源 |

> 水印与存证任务会先写入队列再执行，提交后可以离开页面，完成后资产详情与铃铛会更新。若界面提示 worker 未启用，请运行 `flask tasks run` 或开启 `TASK_WORKER_ENABLED`。

> “上链存证”按钮在未嵌入水印时是禁用的。这是业务约束，不是页面故障。

常用入口：

- `/assets` 资产档案：搜索、标签/格式/上传日期/上传者、类型/园林/状态筛选，按最新/浏览/下载排序。
- `/assets/upload` 上传资产：一次选择多个文件，逐件显示上传/水印/存证进度，失败不影响其余文件。
- `/assets/:id` 资产详情：收藏、复制链接、下载、申请授权、同园林相关资产、证据链、图纸/影像标注、版本历史、讨论、编辑著录信息（标题、说明与标签）；视频可直接播放，PDF 可内嵌预览，GLB/GLTF/STL/OBJ 三维模型可拖拽旋转缩放（均需授权，预览不计下载量，超过 25MB 需手动点击加载）。所有者与资产管理员可在“证据链”页签导出证据包（当前文件、证据链、版本证书、SHA-256 清单与核验说明），并可打开“授权与下载记录”查看被授权方、配额、到期时间、申请进度，直接续期或撤销。
- `/my-assets` 我的资产：查看草稿、待审、已发布、已驳回，提交发布/重新提交/删除；“回收站”页签可查看删除时间并恢复误删资产。
- `/favorites` 我的收藏：集中查看收藏并取消。
- `/collections` 我的合集：按主题组织资产，可在资产详情“加入合集”；合集可设为公开或私有。
- `/downloads` 下载记录：查看授权下载过的资产、授权编号、下载指纹与时间；管理员可切换全平台台账，并按渠道/结果筛选。
- `/trace` 溯源查询：上传图片或输入水印编号核验来源；发现盗用时可提交侵权线索（文件、链接或说明）。
- `/watermark-lab` 水印实验室（需登录）：上传一张图片，真实执行 DCT/QIM 嵌入与 JPEG、噪声、缩放等 8 项攻击，查看 PSNR、NC、水印 ID 是否恢复以及每项耗时，并可下载 Markdown 实验报告；实验只处理临时副本，不写入资产库。
- `/verify-package` 证据包核验（公开）：上传平台导出的 ZIP，检查文件完整性、SHA256SUMS、资产编码、水印、证书与版本哈希，并区分“完整性失败”和“与平台登记不一致”。
- `/admin/infringements` 侵权线索（管理员）：查看疑似盗用线索、举报文件与匹配资产，受理、确认或驳回；支持一次上传最多 20 个文件批量巡检。
- `/license/my` 我的授权：切换“授权记录/申请记录”，查看合同（支持打印/另存 PDF）、撤回申请、下载已生效资产；下载时按授权范围申报用途与地域。
- `/admin/license/usage` 授权使用报表（管理员）：授权状态、配额消耗、超范围拒绝原因、下载趋势与版本待重审清单，可导出当前页 CSV。
- `/settings` 账号设置：维护邮箱、修改密码、开启站内实时通知与邮件通知分组。
- `/admin/notifications` 通知渠道（超级管理员）：查看 SSE/邮件/Webhook 状态，配置系统 Webhook（通用 JSON 或企业微信群机器人）、订阅事件分组并发送测试。
- `/admin/gardens` 园林档案（管理员）：新建、编辑园林名称、历史、坐标与文保信息。
- `/admin/downloads` 下载台账（管理员）：全平台下载明细与汇总。
- `/admin/assets` 资产管理（管理员）：批量嵌水印/上链、批量通过/驳回待审资产，并可导出当前页 CSV。
- `/admin/tasks` 任务队列（管理员）：查看水印/存证的排队、处理中、失败任务，在线 worker 心跳、最老排队任务与积压/超时告警，支持重试与取消。
- `/admin/logs` 操作日志（管理员）：按模块、结果、日期和关键词筛选审计记录；每条日志带服务端 HMAC 签名，可点击“校验日志完整性”核对是否被修改。

资产所有者或管理员可以在资产详情点击“分享核验”，生成免登录链接，设置有效期、访问码、下载权限与下载次数上限。分享页会展示资产信息和完整证据链，链接可随时撤销。

## 4. 关键概念

### 水印状态

- `none` 未嵌入：仅上传，尚未写入标识。
- `embedded` 已嵌入：可以上链、提取与溯源。
- `verified` 已校验：提取结果与记录一致。
- `failed` 失败：算法或文件异常，查看操作日志。

模型、文档、视频没有盲水印能力，这三类资产的 `none` 显示为“不适用（哈希存证）”：它们仍可上链存证，证书按文件哈希与版本签发，证据链会明确标注“不适用盲水印”，不会伪装成已嵌入。影像与矢量仍需完成水印后才能上链。

### 存证状态

- `none` 未存证；`pending` 处理中；`confirmed` 已确认；`failed` 失败。
- 存证证书只有在交易确认后才会生成。

### 资产状态

- `draft` 草稿 → `pending` 待审核 → `published` 已发布；`rejected` 驳回；`deleted` 已删除（管理员可见）。

### 授权流程

`pending` 待一级 → `adm1_approved` 待二级 → `approved` 已通过 → 生成 `License`（`active`）。任一级可驳回。

## 5. 常见问题

**为什么列表里看不到刚上传的文件？**  
新资产是草稿，只有上传者和管理员可见。完成水印、上链并提交发布、管理员审核后才会公开。

**为什么不能上链？**  
先嵌入水印。上链按钮会在水印状态为 `embedded` 或 `verified` 时启用；模型/文档/视频不适用盲水印，可直接按文件哈希存证。

**申请授权后在哪里看进度？**  
“我的授权 → 审批中”查看申请；二级通过后“全部/已生效”会出现授权记录。

**如何把资产发给外部人员核验？**  
资产所有者或管理员在资产详情点击“分享核验”，设置有效期、访问码与下载权限后生成链接。外部人员免登录即可查看资产与证据链；不需要时可在同一弹窗撤销。分享页只展示聚合下载次数，不暴露用户身份、IP 或内部台账明细。

**顶栏铃铛里的待办点过之后还会亮吗？**  
不会。点击待办或“全部已读”后，已读状态按账号保存；业务状态再次变化时会重新变为未读。

**如何替换一件资产的文件？**  
资产所有者或管理员在资产详情“版本历史”点击“上传新版本”，填写变更说明即可。系统会保留旧版本文件并新增版本号，当前文件指向新版本，水印与当前存证状态重置；**已发布或待审资产会退回草稿，必须重新水印、提交发布并通过审核后才能继续对外分发**。证书按版本签发：旧版本证书保留在“版本”页签并可继续打开，新版本需要重新水印存证后才会获得自己的证书；证书页会标注“历史版本”。恢复旧版本也会生成新版本而不是删除历史。若水印/存证任务正在执行，上传会被拒绝（409），等任务结束后再操作；排队中的旧版本任务会自动取消。

**删除资产后还能恢复吗？**  
删除会进入回收站：状态变为“已删除”，有效授权立即撤销并通知被授权方，待审申请取消，排队中的水印/存证任务取消。资产所有者可在“我的资产 → 回收站”查看删除时间并点击“恢复”，资产管理员也可在后台“资产管理”筛选“已删除”恢复；恢复后回到草稿，原授权不会自动恢复，需要重新水印/存证、提交发布并重新授权。回收站卡片不提供详情跳转。删除不会阻塞同一文件重新上传。

**打开视频/PDF/三维模型会立刻下载整个文件吗？**
不会。超过 25MB 的预览会先显示文件大小与“加载预览”按钮，由你决定是否消耗流量；小于 25MB 的视频、PDF 与三维模型仍会自动加载。加载后浏览器通过 1 小时预览票据直接按 Range 读取，不会把整段视频或 PDF 读进 JS 内存。图片始终使用缩略图，点击后才查看原图。

**下载大文件会把整个文件读进浏览器内存吗？**
不会。详情页与“我的授权”下载会先申请一个 120 秒有效的短时票据，再由浏览器直接访问下载地址流式写入磁盘；票据绑定资产、账号、用途与地域，实际下载时服务端会重新校验授权并写入台账，因此不能拿旧票据继续下载已撤销的授权。影像的指纹码仍在开始下载时提示，并记录在下载台账中。

**水印/存证任务提交后页面能关吗？**  
可以。任务已写入数据库队列，后台 worker 会继续执行；重新打开资产详情会看到最新状态。任务卡在排队时可运行 `flask tasks status` 查看是否有在线 worker、是否积压或超时；失败任务可在接口或页面重试；超时任务由 `flask tasks reconcile` 或调度器重新排队。

**为什么证书页显示“历史版本”？**  
证书绑定签发时的文件版本。资产上传新版本后，当前文件需要重新水印与存证，旧证书仍可核验，但会明确标注对应 v1/v2 等历史版本；只有与当前版本绑定的证书才显示“当前版本”。

**证据包里有什么？**  
资产所有者或资产管理员在详情“证据链”页签点击“导出证据包”，会下载一个 ZIP：`manifest.json`（资产、版本、水印、存证、证书与文件哈希）、`evidence-chain.json`、按版本签发的证书 JSON、当前版本原件与水印副本、`SHA256SUMS` 和中文核验说明。超过服务端 200MB 限制或请求 `include_files=0` 时只导出清单与证书；历史版本文件不随包导出。证据包不写入下载台账，临时文件在下载结束后清理。

**如何核验证书或证据包？**  
证书页可直接查看并扫码打开。证据包可在 `/verify-package` 上传核验：系统会检查 ZIP 结构、SHA256SUMS、包内文件哈希，以及资产编码、水印编号、证书和当前/历史版本哈希。结果分为“证据包核验通过”“包内记录与平台登记不一致”“完整性校验失败”，并会说明本地模拟链、历史版本或未包含文件等边界。公开核验只返回资产状态与编号，不返回上传者和台账明细；它证明包内完整性与平台登记一致，不替代司法鉴定。

**怎么确认操作日志没有被改过？**  
管理员在“操作日志”页点击“校验日志完整性”，系统会逐条重算服务端 HMAC：全部有效显示绿色；字段被修改会标出异常日志编号；历史日志未签名会提示运行 `flask audit rebuild --yes` 补签。该机制能发现字段篡改，但不能阻止有数据库权限的人删除整条日志，删除权限仍需独立控制。密钥轮换后也需要重建签名。

**评论和标注有什么区别？**  
“讨论”是围绕资产的文字交流，支持回复、编辑和删除；“标注”是在当前版本影像上框选具体区域，记录问题、备注或建议，并可标记解决。标注绑定文件版本，上传新版本后旧标注只保留在历史版本列表中，不会叠加到新图上。

**授权可以撤销或续期吗？**  
可以。授权管理员、授权方或资产所有者可在后台“已审批”对生效授权续期或撤销。撤销后对方立即无法继续下载，历史下载记录仍保留；续期会同步合同到期时间。独家授权与已有生效授权互斥，冲突审批会被拒绝。

**授权范围是怎么执行的？**  
申请时可选择使用目的、使用渠道、可下载格式、授权地域和下载次数上限，审批通过后这些字段写入授权记录。授权用户下载时必须申报使用目的与地域，系统会核对格式、地域和剩余次数；超出范围会返回 403，并把拒绝原因写入下载台账（管理员可在“超范围拒绝”筛选查看）。使用渠道主要用于合同与审计，下载环节无法自动判断线下渠道；自由文本的用途说明也只用于合同。历史授权没有结构化字段时视为不限制。

**通知在哪里看？**  
审核、授权、任务结果等事件会实时推送到顶栏铃铛（SSE），不需要刷新页面；在“账号设置 → 通知设置”可开启邮件通知并选择分组。邮件需要管理员配置 `MAIL_ENABLED` 与 SMTP 参数，未配置时界面会明确提示，不会假装已发送。超级管理员还可以在“通知渠道”配置系统 Webhook（通用 JSON 或企业微信群机器人），事件按分组推送到外部系统，失败会退避重试。

**发现别人盗用资产怎么办？**  
在 `/trace` 页面提交“侵权线索”：可以上传疑似盗用图片、填写网页链接或文字说明。系统会尝试提取水印并匹配平台资产；管理员在后台“侵权线索”受理后确认或驳回，结果会通过站内通知（以及已开启的邮件）告知举报人与资产权利人。匿名提交也可以，但留下联系方式便于反馈。

**授权会跟着资产新版本走吗？**  
不会。新审批的授权会记录签发时的文件版本；资产上传新版本后，旧授权不能直接下载新文件，需要重新申请并按新版本审批。历史授权没有版本字段时保持不限制，避免破坏旧数据。换版时系统会通知仍绑定旧版本的有效授权，管理员可在“授权审批 → 使用报表”按“仅历史版本授权”筛选处理。

**怎么查看授权使用情况？**  
管理员进入“授权审批 → 使用报表”：可看到有效/到期/撤销数量、配额消耗、近 N 天下载与拒绝趋势、超范围原因排行和资产使用排行；按授权版本、状态、关键词筛选，并可导出当前页 CSV。

**批量上传时每件资产的标题怎么定？**  
队列里每个文件都有独立标题输入框，默认取文件名；描述、标签、所属园林和水印/存证选项应用到本批全部文件，标题仍可逐件修改。

**水印被裁剪后还能溯源吗？**  
可抵抗 JPEG 压缩、噪声和常见缩放；大幅裁剪会破坏嵌入区域，需要结合存证与人工核验。

**水印实验室的结果能说明什么？**  
实验室对当前上传图片真实执行嵌入与攻击，PSNR 衡量嵌入前后差异（一般高于 30dB 肉眼难察觉），NC 衡量提取出的水印图与原始水印的相似度，ID 恢复要求逐字符一致。结果与图片内容有关：JPEG 50 和“缩放 + 压缩”组合攻击在部分实景照片上会失败，页面会如实标记，不会替换样本或重试到成功。实验只处理临时副本，完成后立即清理，不写入资产库。

**授权下载的图片和原图一样吗？**  
授权用户下载影像时，系统会在原盲水印基础上追加一条可见页脚，包含资产编码、授权编号、被授权账号和唯一指纹码；同一授权重复下载复用同一副本，下载台账可凭指纹码定位到具体授权。所有者与管理员下载保持原文件，不追加页脚。

**三维模型为什么预览失败？**  
在线预览优先支持自包含的 GLB；GLTF 需要缓冲与纹理内嵌在文件中（外部 `.bin`/贴图无法通过鉴权预览接口单独读取），STL/OBJ 可直接预览，FBX 暂不支持在线预览。解析失败时页面会提示“可下载后查看”，不影响资产本身。

**AI 功能为什么提示不可用？**  
AI 依赖独立模型与 API Key，默认关闭；关闭时接口明确返回 503，不会伪造结果。

**演示照片是真实的吗？**  
演示库使用 16 张来自 Wikimedia Commons 的苏州园林实景照片，授权信息见本地 `.scratch/demo/photos/ATTRIBUTION.md`。照片不进入代码仓库；生产环境请替换为已获授权的馆藏影像。

## 6. 本地运行

```bash
# 后端
cd backend
pip install -r requirements.txt
python scripts/init_db.py
python run.py

# 前端
cd frontend
npm install
npm run dev
```

- 前端：http://localhost:5173
- 后端：http://localhost:5000
- 健康检查：http://localhost:5000/health

生成带真实照片的演示库（需要本地 `.scratch/demo/photos`）：

```bash
cd backend
python scripts/seed_demo_assets.py --reset
```

默认会给全部演示资产嵌入水印并模拟存证；想跳过耗时处理可加 `--watermark-count 0 --chain-count 0`。

## 7. 测试

```bash
# 后端 370 个用例
cd backend && python -m pytest tests/ -q

# Windows 内存不足时：每个测试文件独立进程运行
cd backend && python scripts/run_tests.py

# 数据库备份 / 恢复
cd backend && python -m flask backup create
cd backend && python -m flask backup list

# 存储巡检（只读，不删除文件）
cd backend && python -m flask storage report

# 前端 51 个单元测试（单 worker，降低内存占用）
cd frontend && npm run test:ci

# Windows 内存不足时：逐文件运行前端测试
cd frontend && npm run test:ci:safe

# 23 个 Playwright 点击流
cd frontend && npx playwright test
```
