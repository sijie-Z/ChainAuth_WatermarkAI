# 使用指南

> 苏州园林数字资产安全分发与溯源系统 · 3 分钟上手

这份文档对应站内 [`/guide`](http://localhost:5173/guide) 页面，按真实业务流程组织。第一次使用建议先读“快速走一遍”，再按角色查看对应章节。

## 1. 平台解决什么问题

园林影像、图纸和三维模型在传播中很容易脱离出处。平台把四件事串成一条证据链：

1. **数字水印**：把资产唯一标识写入影像频域或矢量坐标，压缩、缩放、噪声后仍可提取。
2. **存证记录**：文件哈希、水印标识和权利人信息生成存证记录与证书。默认使用本地模拟链，配置 FISCO BCOS 节点后才写入真实联盟链；证书页会明确标注当前模式。
3. **双重审批授权**：使用申请经一级、二级审批后生成授权记录，下载行为持续回流台账。
4. **全链路溯源**：上传一张图片即可提取水印、定位资产并关联存证与授权记录。

## 2. 快速走一遍（推荐顺序）

| 步骤 | 操作入口 | 使用角色 | 预期结果 |
|------|----------|----------|----------|
| 1 | `/login` | user1 | 进入资产档案，看到“我的授权” |
| 2 | 资产档案 → 上传资产 | 普通用户 / 资产管理员 | 生成草稿，列表出现缩略图 |
| 3 | 资产详情 → 嵌入水印 | 上传者 / 资产管理员 | 水印状态变为“已嵌入”，得到水印 ID |
| 4 | 资产详情 → 上链存证 | 上传者 / 资产管理员 | 生成交易哈希与存证证书 |
| 5 | 资产详情 → 提交发布 → 后台审核 | 上传者 → asset_mgr | 资产进入公开列表 |
| 6 | 资产详情 → 申请授权 | 普通用户 | “我的授权 → 审批中”出现申请 |
| 7 | 后台 → 待审批 | adm1，然后 adm2 | 两级通过后生成生效授权 |
| 8 | 资产详情 → 下载 / 溯源查询 | 被授权用户 / 任何人 | 下载成功；上传图片可溯源 |

> “上链存证”按钮在未嵌入水印时是禁用的。这是业务约束，不是页面故障。

常用入口：

- `/assets` 资产档案：搜索、类型/园林/状态筛选、按最新/浏览/下载排序。
- `/assets/upload` 上传资产：一次选择多个文件，逐件显示上传/水印/存证进度，失败不影响其余文件。
- `/assets/:id` 资产详情：收藏、复制链接、下载、申请授权、同园林相关资产、证据链、图纸/影像标注、版本历史、讨论、编辑著录信息。
- `/my-assets` 我的资产：查看草稿、待审、已发布、已驳回，提交发布/重新提交/删除。
- `/favorites` 我的收藏：集中查看收藏并取消。
- `/collections` 我的合集：按主题组织资产，可在资产详情“加入合集”；合集可设为公开或私有。
- `/downloads` 下载记录：查看授权下载过的资产、授权编号与时间；管理员可切换全平台台账，并按授权下载/匿名分享渠道筛选。
- `/license/my` 我的授权：切换“授权记录/申请记录”，查看合同、撤回申请、下载已生效资产。
- `/admin/gardens` 园林档案（管理员）：新建、编辑园林名称、历史、坐标与文保信息。
- `/admin/downloads` 下载台账（管理员）：全平台下载明细与汇总。
- `/admin/logs` 操作日志（管理员）：按模块、结果、日期和关键词筛选审计记录。

资产所有者或管理员可以在资产详情点击“分享核验”，生成免登录链接，设置有效期、访问码、下载权限与下载次数上限。分享页会展示资产信息和完整证据链，链接可随时撤销。

| 角色 | 权限 | 演示账号 |
|------|------|----------|
| 普通用户 | 浏览已发布资产、申请授权、查看自己的授权/申请 | `user1 / 123456`、`user2 / 123456` |
| 一级审批员 | 授权申请一级审批、资产发布审核 | `adm1 / 123456` |
| 二级审批员 | 授权申请二级复核 | `adm2 / 123456` |
| 资产管理员 | 资产管理、水印、上链、发布审核 | `asset_mgr / 123456` |
| 授权管理员 | 授权台账、审批与合同 | `license_mgr / 123456` |
| 超级管理员 | 全部后台功能 | `admin / admin123` |

演示账号只在开发模式显示在登录页。正式部署前请修改密码或删除账号。

## 4. 关键概念

### 水印状态

- `none` 未嵌入：仅上传，尚未写入标识。
- `embedded` 已嵌入：可以上链、提取与溯源。
- `verified` 已校验：提取结果与记录一致。
- `failed` 失败：算法或文件异常，查看操作日志。

### 存证状态

- `none` 未存证；`pending` 处理中；`confirmed` 已确认；`failed` 失败。
- 存证证书只有在交易确认后才会生成。

### 资产状态

- `draft` 草稿 → `pending` 待审核 → `published` 已发布；`rejected` 驳回；`deleted` 已删除（管理员可见）。

### 授权流程

`pending` 待一级 → `adm1_approved` 待二级 → `approved` 已通过 → 生成 `License`（`active`）。任一级可驳回。

## 5. 常见问题

**为什么列表里看不到刚上传的文件？**  
新资产是草稿，只有上传者和管理员可见。完成水印、上链并提交发布、管理员审核后才会公开。

**为什么不能上链？**  
先嵌入水印。上链按钮会在水印状态为 `embedded` 或 `verified` 时启用。

**申请授权后在哪里看进度？**  
“我的授权 → 审批中”查看申请；二级通过后“全部/已生效”会出现授权记录。

**如何把资产发给外部人员核验？**  
资产所有者或管理员在资产详情点击“分享核验”，设置有效期、访问码与下载权限后生成链接。外部人员免登录即可查看资产与证据链；不需要时可在同一弹窗撤销。分享页只展示聚合下载次数，不暴露用户身份、IP 或内部台账明细。

**顶栏铃铛里的待办点过之后还会亮吗？**  
不会。点击待办或“全部已读”后，已读状态按账号保存；业务状态再次变化时会重新变为未读。

**如何替换一件资产的文件？**  
资产所有者或管理员在资产详情“版本历史”点击“上传新版本”，填写变更说明即可。系统会保留旧版本文件并新增版本号，当前文件指向新版本、水印状态重置；**已发布或待审资产会退回草稿，必须重新水印、提交发布并通过审核后才能继续对外分发**。历史链上存证仍对应旧版本，证据链会标注“当前文件已更新”，恢复旧版本也会生成新版本而不是删除历史。

**评论和标注有什么区别？**  
“讨论”是围绕资产的文字交流，支持回复、编辑和删除；“标注”是在当前版本影像上框选具体区域，记录问题、备注或建议，并可标记解决。标注绑定文件版本，上传新版本后旧标注只保留在历史版本列表中，不会叠加到新图上。

**批量上传时每件资产的标题怎么定？**  
队列里每个文件都有独立标题输入框，默认取文件名；描述、标签、所属园林和水印/存证选项应用到本批全部文件，标题仍可逐件修改。

**水印被裁剪后还能溯源吗？**  
可抵抗 JPEG 压缩、噪声和常见缩放；大幅裁剪会破坏嵌入区域，需要结合存证与人工核验。

**AI 功能为什么提示不可用？**  
AI 依赖独立模型与 API Key，默认关闭；关闭时接口明确返回 503，不会伪造结果。

**演示照片是真实的吗？**  
演示库使用 16 张来自 Wikimedia Commons 的苏州园林实景照片，授权信息见本地 `.scratch/demo/photos/ATTRIBUTION.md`。照片不进入代码仓库；生产环境请替换为已获授权的馆藏影像。

## 6. 本地运行

```bash
# 后端
cd backend
pip install -r requirements.txt
python scripts/init_db.py
python run.py

# 前端
cd frontend
npm install
npm run dev
```

- 前端：http://localhost:5173
- 后端：http://localhost:5000
- 健康检查：http://localhost:5000/health

生成带真实照片的演示库（需要本地 `.scratch/demo/photos`）：

```bash
cd backend
python scripts/seed_demo_assets.py --reset
```
